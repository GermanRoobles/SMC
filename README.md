# SMC TradingView - Smart Money Concepts Trading System

## 🚀 Live Demo
[Deploy en Streamlit Cloud](https://tu-app.streamlit.app)

## 📊 Descripción
Sistema avanzado de trading basado en Smart Money Concepts (SMC) con:
- ✅ Análisis SMC en tiempo real
- ✅ Backtesting integrado
- ✅ Machine Learning para predicciones
- ✅ Visualización TradingView-style
- ✅ Alertas Telegram

## 🛠️ Tecnologías
- **Streamlit**: Interfaz web
- **Pandas/Numpy**: Análisis de datos
- **Plotly**: Visualización avanzada
- **Scikit-learn**: Machine Learning
- **YFinance**: Datos de mercado

## 🚀 Deploy
1. Fork este repositorio
2. Conectar con Streamlit Cloud
3. Deploy automático

## 📈 Características
- Análisis SMC (FVG, Order Blocks, Liquidity)
- Backtesting con métricas completas
- ML Predictor y Signal Generator
- Multi-timeframe analysis
- Real-time alerts

## 🔧 Configuración
- Python 3.9+
- Dependencias en requirements.txt
- Configuración en .streamlit/config.toml
